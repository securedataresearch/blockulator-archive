# blockulator-archive

The earlier life of [Blockulator](https://github.com/securedataresearch/blockulator), kept for the record: the
on-chain games, the 25 single-purpose Vyper calculators, the futures market, the text and image store, the pixel
badges and the discussion board, with the single-page app that served them. All of it ran on Sepolia.

None of this is part of Blockulator's two libraries, BL127 and BL19, and nothing here is maintained. The paths
are the ones the files had in the main repository, with their history.

| path | what it is |
|---|---|
| `contracts/src/games/` | the Vyper games |
| `contracts/src/tools/` | 25 calculators, one contract each |
| `contracts/src/market/` | the futures market |
| `contracts/src/content/` | on-chain text and image storage |
| `contracts/src/identity/` | pixel badges |
| `contracts/archive/discussions/` | the discussion board |
| `contracts/build/abis/` | the ABIs the app fetched |
| `static/js/legacy/`, `static/css/legacy/` | the app |
| `content/`, `templates/`, `static/js/islands/` | the two site pages that mounted it |
